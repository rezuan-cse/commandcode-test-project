# Documentation Taste
- Wants user-facing documentation (user manuals) written in plain, simple language using short, easy-to-understand sentences, aimed at non-technical everyday users rather than developers. Confidence: 0.75
- Wants docs to explicitly spell out who can do what — a clear role-by-role breakdown of permissions/actions. Confidence: 0.65
- Wants documentation to include concrete worked examples with sample values that the reader can follow along with step by step. Confidence: 0.7
- Treats the user manual's worked example as a hands-on acceptance test — follows it "step by step" against the real app and expects the on-screen figures to match the documented numbers exactly. Confidence: 0.65
- Prefers client-facing docs delivered in a shareable Word format (.docx) alongside the Markdown source — asks for "also a docx copy" of the manual, expecting both to exist. Confidence: 0.55
